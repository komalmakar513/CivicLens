
# CivicLens
### Community Problem Intelligence Platform

CivicLens is a full-stack web application designed to help citizens report and track public infrastructure problems.

## Problem Statement
Community problems such as potholes, garbage accumulation, broken streetlights and waterlogging are often reported through scattered channels.

CivicLens provides a centralized platform to organize and track these issues.

## Key Features
- User Authentication
- Community Problem Reporting
- Interactive Maps
- Duplicate Report Detection
- Community Support
- Priority Scoring
- Admin Dashboard
- Status Tracking
- Analytics and Reporting

## Technology Stack
- React.js
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Leaflet
- Recharts
